# הסבר על המערכת

## Backend (הצד הלוגי של השרת)
*   **שפה**: האפליקציה כתובה ב-PHP.
*   **מבנה**: הקוד מאורגן בצורה מודולרית. הקבצים החשובים נמצאים בתיקייה `core`:
    *   `init.php`: זהו הקובץ שמתחיל את כל האפליקציה. הוא טוען את כל ההגדרות והקבצים הנחוצים, מתחיל את ה-"session" (החיבור של המשתמש), ובודק הרשאות גישה לדפים השונים.
    *   `auth.php`: זהו המוח של האבטחה. הוא אחראי על כל מה שקשור לאימות משתמשים: התחברות, הצפנת סיסמאות, יצירת טוקנים לאבטחה (כמו CSRF), אימות אימיילים ואיפוס סיסמה.
    *   `user.php`: קובץ זה מנהל את כל הפעולות שקשורות למשתמשים, כמו רישום משתמש חדש, עדכון פרטים, קבלת רשימת משתמשים לפי תפקיד, וכו'.
    *   `db.php`: קובץ זה מנהל את החיבור למסד הנתונים (כנראה MySQL/MariaDB) ומספק דרך נוחה לשלוף ולהכניס נתונים.
*   **נקודת כניסה**: הקובץ `index.php` הוא הדף הראשון שנטען. הוא בודק אם המשתמש מחובר, ואם לא - מפנה אותו לדף ההתחברות (`pages/login.php`).

## Docker
בקבצים שנסקרו, **לא נמצאו קבצי הגדרות של Docker** (כמו `Dockerfile` או `docker-compose.yml`). זה אומר שככל הנראה הפרויקט כרגע לא מוגדר לרוץ בסביבת Docker, אלא מותקן ישירות על שרת ווב (כמו Apache או Nginx) עם PHP ומסד נתונים.

## אבטחה
המערכת מיישמת מספר מנגנוני אבטחה חשובים:
*   **הצפנת סיסמאות**: סיסמאות לא נשמרות כטקסט רגיל, אלא מוצפנות באמצעות אלגוריתם חזק ומודרני (`BCRYPT`). זה אומר שגם אם מישהו יפרוץ למסד הנתונים, הוא לא יוכל לראות את הסיסמאות.
*   **סשנים מאובטחים (Secure Sessions)**: המערכת דואגת שהתקשורת של המשתמש המחובר תהיה מאובטחת. היא מחדשת את מזהה הסשן מדי פעם כדי למנוע "גניבת סשנים".
*   **הגנה מ-CSRF (Cross-Site Request Forgery)**: המערכת משתמשת בטוקנים כדי לוודא שפעולות רגישות (כמו שינוי סיסמה) מבוצעות רק על ידי המשתמש עצמו מתוך האתר, ולא על ידי גורם זדוני מאתר אחר.
*   **אימות אימייל**: משתמשים חדשים חייבים לאמת את כתובת האימייל שלהם לפני שהם יכולים להתחבר. זה מוודא שהאימייל שייך להם.
*   **בקרת גישה מבוססת תפקידים (RBAC)**: המערכת בודקת את התפקיד של המשתמש (למשל, 'מורה' או 'תלמיד') ונותנת לו לגשת רק לדפים המורשים לו.

## יצירת משתמשים ראשוניים
בעת עליית האפליקציה, הקובץ `core/init.php` בודק אם קיימים משתמשי ברירת מחדל:
*   מורה: `admin` / `admin123`
*   תלמיד: `student` / `student123`

אם המשתמשים אינם קיימים, המערכת תיצור אותם באופן אוטומטי.
